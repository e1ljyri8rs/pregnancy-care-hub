# 腔内超声的“那些事”~~

> 更新时间：2026-09-16 (UTC+8)

人体可以进行腔内超声的部位有食道，直肠和阴道这三个地方。今天就带大家走进我们妇幼专科医院的腔内超声：经**直肠**和经**阴道**超声的检查吧。

 
虽然“腔内超声”已经普及很多年了，但是许多患者一看到医生开了“阴道超声”检查单就感到难为情，甚至不愿意做。很多人都会问，阴道超声是B超吗？是彩超吗？有阴道出血能不能做？做了会不会得阴道炎？好多人同用一个“东西”检查，那会不会感染？会不会传染疾病？怀孕了能做吗？同样的看到“直肠超声”检查单，家属和病人都会产生疑问：没有性生活的女孩可以做吗？会不会有疼痛？会不会出血？
**首先我们来了解一下阴道超声是怎么一回事？**

**No.1 什么是阴道超声？**

 
阴道超声检查，全名经阴道妇科彩色多普勒超声检查，简称阴超，又称腔内B超，是将超声探头套上专用隔离套后放入阴道进行超声诊断的方法。

**No.2 阴道超声**

**有什么样“魔性”的优势**

**能广泛应用于医学检查呢？**

 
让我们一起来看看阴超到底有哪些“特长”吧：
1.阴超探头频率高、分辨率强，且离靶器官（子宫、卵巢等）更近，不受腹壁厚度（肥胖患者）、肠道内气体影响，尤其对后位子宫、宫腔内、卵巢及附件区的病变显示更好，不需充盈膀胱（避免憋尿之“痛”）。

2.阴超要求简单，只需要排空膀胱即可，操作时间短，图像清晰，缩短候诊时间，提高诊疗效率。对鉴别宫内孕和宫外孕、检测卵泡的情况绝对优于经腹彩超，还能更早的看清孕囊位置、胚芽及胎心搏动等情况，结合三维超声可以进一步鉴别宫角妊娠与间质部妊娠。

**No.3 会感染吗？**

 

      当然不会！

      因为呢我们实施的是：“一患一用一丢弃”，即腔内超声检查时每个人都有一次性专用的灭菌隔离膜和巾单，医生在检查时都得戴一次性手套，医院也会有专门的感染管理科不定期进行督查，目前并没有研究证实阴道超声会增加感染的风险。 

（PS:当然咱们所说的安全的前提得是在正规的医院呦，黑诊所可不行哟~）。

**No.4会痛吗？**

 

      当然不会！

     阴道超声是一项无创的检查。探头放进去时，只是自己能够感受到一点点异物感，有个东西进入，当然在医生检查卵巢时，会有一点酸胀感，这是正常的现象。

**No.5怀孕早期**

**可以做阴道B超吗？**

      可以。在孕早期进行阴道超声检查，并不会影响到胎儿的生长发育情况。目前没有研究证据显示阴超对胎儿有害，国外现在基本上第一次做产检，都是做的阴超。宝妈们不用过于焦虑，当然如果无法克服心理障碍，一般的早孕检查做腹部B超也是可以的，但是如果怀疑有宫外孕或其他病症，就要听医生的做阴超。

      目前临床上所应用的B超的超声波是一种物理波，不像X线那样具有辐射及生物效应，对人体组织没有什么伤害。

      当然阴道超声也有不能做的人群——无性生活史禁止做阴道超声检查。那么对于这一群无性生活史的“女孩子们”我们采用的是腔内的另一种方法——直肠超声检查。

      毋庸置疑，经直肠超声检查就是将探头置于直肠内进行的超声检查。

      其实经阴道与经直肠检查是同一个原理，只是探头放置的位置不一样，阴道超声检查适用于有性生活史，直肠超声检查适用于无性生活史。

     附：经腹部、经阴道、经直肠超声检查子宫、卵巢、双附件的注意事项：

     1. 经腹部超声检查：有、无性生活都可以进行检查，检查前需要充盈膀胱，也就是常说的“需憋尿”。

     2. 经阴道超声检查：有性生活史者才可以进行检查，无需充盈膀胱，且检查前需要把尿排空，否则会影响检查。

     3. 经直肠超声检查：一般来说针对无性生活史者，需要将大小便都排空。因为直肠毛细血管比较丰富、粘膜比较薄弱，如患者既往有便秘、大便干燥、痔疮或肛管、肛周皮肤破损，做完直肠超声部分人可能会有肛门不适、红肿、甚至少量出血的症状，这是正常的，不必紧张，只要稍作休息以上症状就可消失。若对此检查还有顾虑，可以选择不检查，找开单医生改医嘱。

     定期的妇科超声检查是早期发现妇科疾病相对有效方法，我们着力于为广大女性朋友提供更准确、更全面、更便捷、更安全的服务。
