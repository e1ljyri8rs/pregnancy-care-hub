# 剖宫产全攻略：术前术后安心指南，让你无忧迎接新生命！

> 更新时间：2026-09-17 (UTC+8)

**剖宫产术前术后宣教**

准备迎接宝宝，心情既紧张又期待？

想知道剖宫产全过程是怎么回事吗？

来，我们一起看看吧！

**手术前的准备**

1.手术前一日记得洗澡，或擦拭手术部位皮肤，保持清洁。（我们在浴室备有防滑垫，洗澡时一定要注意预防跌倒哦！）

2.手术前一日晚上请您好好休息，注意保暖，剖宫产术前禁食8h, (油炸、脂肪及肉类不易消化食物需禁食8h以上)，禁饮6小时。

**手术当天要怎么做？**

1.手术当日清晨您可以洗脸刷牙，但不能进食水。术前请您将假牙，手表，手机，首饰等取下，修剪指甲，身上不要带钱及贵重物品。请您不要化妆，涂口红，指甲，以免病情变化时影响观察。

2.如果您是长发还请您把头发编成辫子扎在侧面，这样手术时躺下会舒服些。

3.请你换好手术衣，准备好后在病床上等待手术室护士接您。

**手术时要怎么做？**

4、进手术室时，病房护士和手术室护士会与您核对身份信息，请您配合！

5、手术床比较窄，您在床上时不要随意翻身，以免坠床。

6、手术过程中会使用许多仪器设备，会发出声响，如果您是清醒状态，请您不要感到恐惧和紧张，手术医生，麻醉师和手术室护士都会在您身边陪伴您。全身麻醉的话整个手术过程中您是睡着的，一直到手术做完，手术完成后请您配合麻醉医生好好呼吸，直到您呼吸平稳。

7、手术结束后我们会有护士送您回到病房。

**手术后**

**手术当日：**

1.术后护士会根据您的情况，告知您饮食等注意事项。

2.一般术后六至八小时取沙袋，取沙袋后床上适当翻身活动，至少每两小时翻身一次，可促进肠蠕动利于排气及恶露排出，及时更换护理垫及保持会阴清洁。（翻身方法如下图）

3.保持吸氧管、输液通道、镇痛泵、尿管等的通畅，避免受压，输液完毕时家属需及时呼叫我们，尿袋充盈时需及时放尿。

4.若你有不适，或护理垫出血较多等异常情况，请及时呼叫我们。

5.按需哺乳，每天母乳喂养次数不少于8次，10-12次为宜，坚持夜间哺乳。                 

** 术后一日：**

1、 每日清洁会阴部，避免感染，可做力所能及的自我护理(如床上刷牙、洗脸、梳头等)。

2、 床上翻身活动，肛门未排气前，继续进食流质饮食;肛门排气后，少量多餐，从软食过渡到普食，避免进食过多，引起腹胀等不适。

3、停心电监护及保留尿管后，可适当下床活动，活动前在床旁坐位休息，无头晕再由家属搀扶站立，无不适后，才开始活动，下床时请注意安全，避免跌倒。 

4、 取尿管后可穿内裤，勤换卫生巾，尽早自解小便，争取两小时内解第一次小便，尽量排空膀胱，如果排尿困难，及时告知主管护士。

5、术后血性恶露一般维持3-4天，如超过平时月经量，及时告知主管护士。 

**术后二日：**

1、保证充分睡眠及休息，及时进食，促进产后恢复。

2、关注子宫收缩及阴道流血情况，一般术后48小时内可排气，注意有无腹胀。

3、持续母乳喂养，让新生儿多吸吮;如有乳房肿胀、喂养困难，请告知主管护士。

**术后三、四日：**

1、关注子宫收缩恢复情况及切口愈合情况。

2、术后三日一般自解大便，如果排便困难，及时告知主管护士。

3、适当增加活动量，适当进食水果及蔬菜。
